# Add this design to your GitHub profile

1. Extract this ZIP.
2. Open https://github.com/harix28/harix28.
3. Back up your existing README and assets if you want to keep them.
4. Use Add file → Upload files. Upload README.md and the whole assets folder into the repository root. Keep the folder name assets.
5. Commit the changes to the default branch. Your profile will use the new README.

Do not upload only the ZIP: GitHub needs the extracted files. SETUP.md does not need to be uploaded.
